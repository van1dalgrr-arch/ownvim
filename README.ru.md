# ownvim

🇬🇧 [English](README.md)

**Своя IDE в терминале для бэкенда на базе Neovim.** Go, Rust, Python, JavaScript / TypeScript, SQL, Docker, C/C++ —
и любой другой язык, инструменты для которого ставятся сами. Всё, что видно и как работает, настраивается одним
JSON-файлом, без Lua. Редактор сделан так, чтобы за ним можно было спокойно сидеть по пять часов подряд.

## Что внутри

- **Как IDE.** У каждой панели своё место. Слева проект, поиск с заменой, изменения git, структура, тесты, база,
  расширения. Снизу терминал, запуск, проблемы и задачи. Режимы Код · Тесты · Отладка · Git · База переключаются одной
  клавишей, «▶ api» справа вверху, как в GoLand. Поиск везде — `пробел пробел`. Раскладка помнится для каждого проекта.
- **Языки как в GoLand.** У Go, Rust, Python и JS/TS одинаково:
  - ▶ слева от `main` и тестов: `пробел r x` запускает, `r X` — под отладчиком;
  - тесты в фоне при сохранении: `✓ 42` / `✗ 1` в статусе, упавшая проверка — ошибкой на своей строке;
  - конфигурации запуска (каждый `package main`, бинарник cargo, Django / FastAPI, `npm run dev`);
  - покрытие, черновик (`пробел r g` / `r R` / `r p`), сниппеты, задачи.

  Python сам находит `.venv` / poetry / conda. Rust раскрывает макросы и объясняет ошибки (`пробел R`).
- **Бережно к глазам.**
  - Мягкий фильтр поверх любой темы: контраст и насыщенность чуть ниже, фон никогда не чисто чёрный.
  - Вечером тема плавно теплеет, как Night Shift, но только в редакторе.
  - Каждые 20 минут — тихая подсказка посмотреть вдаль (правило 20-20-20).
  - Мягкие темы velvet и linen.
  - Смена режима без вспышек; пока печатаешь, ошибки не мигают на недописанном слове.
- **Плавно.** Курсор скользит, и при наборе тоже, как smooth caret в VS Code. Прокрутка мягко останавливается.
  Сплиты и панели выдвигаются, всплывающие окна проявляются, цвета режимов перетекают. `:Smooth` показывает, что
  работает, и проигрывает демо.
- **Быстро.** Код на экране через ~70 мс после запуска, буква — через ~6 мс после нажатия.
- **Настройка как в VS Code.**
  - `settings.jsonc` с дополнением ключей, описаниями и проверкой; сохранил — применилось сразу.
  - Настройки списком с поиском (`cmd-,`).
  - Панель расширений: включить или выключить модуль одной клавишей, магазин плагинов.
- **Всё ставится само.** Плагины, парсеры, языковые серверы, форматтеры, линтеры и отладчики ставятся при первом
  запуске и при первом открытии файла нового языка.
- **Для бэкенда.**
  - SQL: дополнение из миграций и базы проекта; миграции (новая / up / down / статус), down пишется сам.
  - Docker: живой `compose.yaml`, вес слоёв в Dockerfile, отладка в контейнере. Kubernetes.
  - API: эндпоинты Gin, `.http`-запросы.
- **Расширяется без кода и на Go.**
  - Без кода — JSONC-набор (`:PluginNew`): клавиши, задачи, свои проверки с ошибками на строках.
  - На Go — как у встроенных возможностей (`:GoExtensionNew`): команды, подсказки дополнения, описания по `K`,
    исправления, панели; сохранил — работает.
- **Красиво.** 41 своя тема (gopher, oxide, nocturne, ink и harbor — под Go и Rust) и популярные темы из VS Code; любую
  тему с Marketplace можно поставить через `:ThemeInstall`. Иконки папок по смыслу, рамки в стиле промпта, статусная
  строка и вкладки собираются из JSON, есть Error Lens и Sticky Scroll.
- **И в VS Code.** `vscode/` — отдельная копия VS Code с теми же буквами (`пробел r x`, `пробел r m`…) и своим
  расширением: ▶, SQL из миграций, Docker, эндпоинты. Основной VS Code она не трогает.

## Установка

Нужны Neovim 0.12+, git, Go, `tree-sitter`, `ripgrep` и шрифт Nerd Font (в Ghostty значки встроены).

```bash
brew install neovim tree-sitter ripgrep go
git clone https://github.com/van1dalgrr-arch/ownvim ~/dev/ownvim
ln -s ~/dev/ownvim ~/.config/ownvim
echo 'alias ownvim="NVIM_APPNAME=ownvim nvim"' >> ~/.zshrc && exec zsh
ownvim        # первый запуск сам поставит всё нужное (~1 минута)
```

С [dotfiles](https://github.com/van1dalgrr-arch/dotfiles) всё это делает `install.sh`. Для Rust:
`brew install rustup && rustup default stable`, для Python — `brew install uv`.

## Первые клавиши

| | |
|---|---|
| `пробел пробел` | найти что угодно: файл, символ, команду |
| `пробел e` · `пробел sp` · `пробел ge` | дерево · поиск по проекту · изменения git |
| `пробел r x` / `r X` | ▶ запустить / отладить то, где курсор (main или тест) |
| `пробел r r` | запустить выбранную конфигурацию (справа вверху) |
| `пробел ca` · `F12` · `shift-F6` | исправления и действия · к объявлению · переименовать |
| `alt-s` | выбрать тему с предпросмотром |
| `пробел fc` · `cmd-,` | мои настройки файлом · списком |
| `пробел` и подождать | все клавиши (which-key) |

13 клавиш на первый день и переход с VS Code — в [Начале работы](docs/getting-started.md).

## Настройка за минуту

```jsonc
// settings.jsonc — пробел fc. Только то, что отличается от defaults.jsonc
{
  "theme": { "dark": "velvet", "light": "linen" },     // по системе; alt-s — выбор с предпросмотром
  "soft": { "night": { "from": "20:00" } },            // вечер для глаз начинается раньше
  "animations": { "scroll": { "duration_ms": 300 } },  // прокрутка ещё мягче
  "statusline": { "style": "frame" },
  "options": { "relativenumber": true },               // любая опция Neovim
  "modules": { "minimap": true },                      // включить модуль
  "keys": { "n <leader>z": ":Lazy" },                  // своя клавиша
  "plugins": { "folke/zen-mode.nvim": { "cmd": "ZenMode" } },  // любой плагин
}
```

## Об авторстве

ownvim — моя идея и мой замысел: что должно быть в редакторе, как он выглядит и работает, что неудобно и что
исправить. Но Lua и Neovim — не мой стек, поэтому **большую часть кода и документации написала нейросеть (Claude)**
по моим требованиям, а я проверял результат в работе.

Идеи взяты из LazyVim, VS Code, GoLand и Zed. Код — ~16 000 строк Lua в `lua/own/` и ~5 500 строк Go-ядра в `core/`
(логика переезжает с Lua на Go по частям; уже на Go — движок настроек, мост, Docker, эндпоинты, `.http`-клиент,
тесты в фоне для Go и Rust, проверки). План развития — [ROADMAP](ROADMAP.md).
