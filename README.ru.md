# ownvim

🇬🇧 [English](README.md)

**Своя IDE в терминале для бэкенда на базе Neovim.** Go, SQL, Docker, C/C++, Python, Rust — и любой другой язык,
инструменты для которого ставятся сами. Всё, что видно и как работает, настраивается одним JSON-файлом, без Lua.

- **Как IDE.** У каждой панели своё место: слева проект, структура, тесты или база, снизу терминал, запуск,
  проблемы и задачи. Режимы Код · Тесты · Отладка · Git · База одной клавишей, «▶ api» справа вверху, как в GoLand,
  поиск везде на `пробел пробел`. Раскладка помнится для каждого проекта.
- **Быстро.** Код на экране через ~70 мс после запуска, буква — через ~6 мс после нажатия.
- **Настройка как в VS Code.** `settings.jsonc` с дополнением ключей, описаниями и проверкой; сохранили — применилось
  сразу, без перезапуска.
- **Всё ставится само.** Плагины, парсеры, языковые серверы, форматтеры и линтеры — при первом запуске и при
  первом открытии файла нового языка.
- **Для бэкенда.** ▶ у `main` и тестов, тесты в фоне, отладчик с подключением к Docker, генерация Go-кода, эндпоинты Gin,
  `.http`-запросы, базы данных, живой `compose.yaml`, вес слоёв в Dockerfile.
- **Расширяется без кода и на Go.** Без кода — JSONC-набор: клавиши, задачи, свои проверки с ошибками на строках
  (`:PluginNew`). На Go — всё, как у встроенных возможностей: команды, подсказки в меню дополнения, описания по `K`,
  исправления в `пробел ca`, свои панели и статусная строка; сохранил — работает без перезапуска (`:GoExtensionNew`).
- **Красиво.** 60+ тем (свои, популярные из VS Code и любая с Marketplace по `:ThemeInstall`), иконки папок по смыслу,
  статусная строка и вкладки из JSON, Error Lens, Sticky Scroll, плавный курсор.

## Установка

Нужны Neovim 0.12+, git, Go, `tree-sitter`, `ripgrep` и шрифт Nerd Font (в Ghostty значки встроены).

```bash
brew install neovim tree-sitter ripgrep go
git clone https://github.com/van1dalgrr-arch/ownvim ~/dev/ownvim
ln -s ~/dev/ownvim ~/.config/ownvim
echo 'alias ownvim="NVIM_APPNAME=ownvim nvim"' >> ~/.zshrc && exec zsh
ownvim        # первый запуск сам поставит всё нужное (~1 минута)
```

С [dotfiles](https://github.com/van1dalgrr-arch/dotfiles) всё это делает `install.sh`.

## Настройка за минуту

```jsonc
// settings.jsonc — пробел fc. Только то, что отличается от defaults.jsonc
{
  "theme": "onedark",                                  // или alt-s — выбор с предпросмотром
  "icons": { "theme": "material" },
  "statusline": { "style": "arrows" },
  "options": { "relativenumber": true },               // любая опция Neovim
  "modules": { "minimap": true },                      // включить модуль
  "keys": { "n <leader>z": ":Lazy" },                  // своя клавиша
  "plugins": { "folke/zen-mode.nvim": { "cmd": "ZenMode" } },  // любой плагин
}
```

## Об авторстве

ownvim — моя идея и мой замысел: что должно быть в редакторе, как он выглядит и работает, что неудобно и что
исправить. Но Lua и Neovim — не мой стек, поэтому **большую часть кода и документации написала нейросеть (Claude)**
по моим требованиям, а я проверял результат в работе.

Идеи взяты из LazyVim, VS Code, GoLand и Zed. Код — ~8700 строк Lua в `lua/own/` и Go-ядро в `core/` (переносим логику с Lua на Go по частям; уже на Go — движок настроек, мост, Docker, эндпоинты, `.http`-клиент, тесты в фоне, проверки); план развития — [ROADMAP](ROADMAP.md).
