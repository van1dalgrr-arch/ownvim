# ownvim — план

Полноценная IDE в терминале для бэкенда: Go (главный), SQL, Docker, немного Python, иногда Rust.
Автодополнение, форматирование, анализ кода. Всё, что видно, — своё и настраивается в `settings.jsonc`.

## Решения

- **Главное — всё через settings.jsonc.** Если что-то можно сделать настройкой, а не кодом, — это настройка:
  языки, серверы и их settings, форматтеры, линтеры, дополнение, ошибки, клавиши, модули, плагины, тема, иконки, шрифт.
  Откуда брать серверы и форматтеры — тоже настройка: `"tools": { "install": "mason" | "system" }` (по умолчанию mason).
- **Вид свой, механика готовая.** Свои: движок тем, тема иконок, статусная строка, дашборд, вкладки.
  Готовые под капотом: дополнение (blink), поиск и дерево (snacks), treesitter, LSP (встроенный в nvim 0.12),
  форматирование (conform), линтеры (nvim-lint).
- **Можно дорасти до «почти всё своё».** Поиск, дерево и меню дополнения подключаются через модуль с
  выбором движка (`"picker": { "engine": "snacks" }`) — свой движок потом встаёт рядом, без переделки остального.
- **Шрифт — в settings.jsonc** (`"font": { "family", "size" }`): ownvim переписывает конфиг Ghostty.
  Работает только в Ghostty — в другом терминале шрифт задаёт он.
- **Никакого LazyVim.** Только lazy.nvim как менеджер плагинов.
- **Настройки — в самом ownvim**, `settings.jsonc` поверх `defaults.jsonc`.

## Этапы

1. ✅ **Ядро и база** — настройки в JSONC с применением на лету, клавиши, поиск, treesitter, правка, темы.
2. ✅ **IDE** (языковые серверы, дополнение, форматирование, линтеры, тесты, отладчик, база) — LSP, дополнение, форматирование при сохранении, линтеры, переход/поиск ссылок/переименование,
   code actions, подсказки типов. Языки: Go (gopls, gofumpt + goimports, golangci-lint, тесты, dlv),
   SQL (дополнение, форматирование, запросы к Postgres), Docker (Dockerfile и compose, hadolint,
   контейнеры), Python (basedpyright, ruff), Rust (rust-analyzer, rustfmt). Серверы и форматтеры — в
   settings.jsonc (`"lsp"`, `"format"`, `"lint"`): добавить язык — строка, а не код.
3. ⏳ **Дизайн — как в VS Code, максимально гибко** (всё в settings.jsonc, всё выключается):
   1. ✅ **Движок тем** — тема = JSON (палитра, синтаксис, интерфейс, правки любых групп); `:ThemeNew` — своя,
      сохранил — перекрасилось; `:ThemeInstall` — тема из VS Code (Open VSX / Marketplace), конвертируется сама;
      тёмная/светлая по системе; темы-плагины (tokyonight…) работают как раньше.
   2. ✅ **Темы иконок** — JSON «тип файла → значок + цвет» (Nerd Font: SVG-иконки VS Code терминал не покажет),
      несколько наборов, `:IconThemeInstall`; везде — дерево, поиск, вкладки, статусная строка.
   3. ✅ **Свой интерфейс** — статусная строка из блоков в JSON (стили: пузыри, плоский, наклонный), вкладки как в
      VS Code, хлебные крошки, стартовый экран из JSON.
   4. ✅ **Шрифт** — `"font": { family, size, ligatures, line_height }` → Ghostty; `:FontInstall` — Nerd Fonts / Google Fonts
      (значки Nerd Font у Ghostty встроены — подходит любой шрифт).
   5. **Плавность и детали VS Code** — плавный курсор и прокрутка, цветные пары скобок, липкая шапка функции, миникарта;
      каждое — отдельно вкл/выкл.
   6. **Старт снова ~20 мс.**
4. **Git и инструменты** — знаки изменений, blame, diff, lazygit; эндпоинты Gin, `.http`-запросы,
   ▶ у main и тестов, фоновые тесты, Claude.

После каждого этапа — проверка руками и скриншот. Когда ownvim догонит LazyVim-сборку, он станет `nvim`.
