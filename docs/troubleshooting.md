# Если что-то не так

[← Документация](README.md)

**Начните с `:OwnHealth`** (`пробел uX`) — проверка настроек, программ, серверов, форматтеров, линтеров, парсеров,
шрифта, темы и скорости старта. У каждой проблемы написано, как её исправить.

## Настройки

| симптом | что делать |
|---|---|
| строка в `settings.jsonc` подчёркнута | наведите курсор — в сообщении сказано, что не так и как правильно |
| «settings.jsonc не прочитан, работаю на умолчаниях» | в файле ошибка JSON — она подсвечена на своей строке; исправьте и сохраните |
| поменял настройку — ничего не изменилось | включение модулей, плагины, стартовый экран — только после `:restart` |
| всё сломалось | переименуйте `settings.jsonc` — ownvim запустится на умолчаниях; возвращайте строки по одной |

## Языки

| симптом | что делать |
|---|---|
| нет ошибок, переходов, дополнения | `пробел cl` — какие серверы подключены; `пробел cL` — перезапустить; `:Mason` — что поставлено |
| сервер не ставится | `:OwnHealth` и `~/.local/state/ownvim/mason.log`; некоторым серверам нужен сам язык (Node, Java, Ruby…) |
| Rust: нет rust-analyzer / rustfmt | `brew install rustup && rustup default stable` |
| автоустановка выбрала не тот сервер | `:AutoTools язык` — забыть и решить заново; или `"auto": { "languages": { "язык": { "lsp": ["свой"] } } }` |
| для языка ничего не нужно | `"auto": { "languages": { "язык": false } }` |
| файл форматируется не так | `пробел cF` — чем форматируется; `пробел uf` — выключить на время; список — раздел `format` |
| ошибки мельтешат во время набора | `"modules": { "error_lens": { "insert": false } }` |

## Внешний вид

| симптом | что делать |
|---|---|
| вместо значков — квадраты | нужен шрифт Nerd Font (в Ghostty значки встроены) или `"icons": { "theme": "ascii" }` |
| тема не та после перезапуска | `"theme"` в `settings.jsonc` сильнее выбранной в `alt-s`; `"theme": "auto"` — брать из `alt-s` |
| не меняется шрифт | шрифт задаёт терминал; `:Font` работает в Ghostty |
| картинка сбоку не видна | нужен терминал с протоколом kitty (Ghostty, kitty, WezTerm), не tmux; jpg/webp — ImageMagick |

## Docker

| симптом | что делать |
|---|---|
| в compose.yaml нет статусов | проверьте `docker ps` в терминале; «docker не запущен» — запустите Docker / OrbStack; файл должен называться `compose.yaml` / `docker-compose.yml` |
| в Dockerfile нет веса слоёв | образ ещё не собран или называется иначе — `:DockerLayers` и выбрать образ |
| вес слоёв устарел | пересоберите образ |

## Плагины и скорость

| симптом | что делать |
|---|---|
| плагин не встал | `:Lazy` (`пробел l`) — ошибки установки и кнопка «обновить» |
| медленный старт | `:OwnHealth` покажет время; подробно — `NVIM_APPNAME=ownvim nvim --startuptime /tmp/st.txt +qa` |

## Логи

`~/.local/state/ownvim/`: `lsp.log`, `mason.log`, `conform.log`, `dap.log`, `neotest.log`, `nvim.log`.
История уведомлений — `пробел n`.
