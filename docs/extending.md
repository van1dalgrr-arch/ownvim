## Плагины

### Магазин

`:Plugins` (`пробел L`) — каталог [awesome-neovim](https://github.com/rockerBOO/awesome-neovim): ~1400 плагинов
с описаниями и разделами, поиск по всему, `●` — уже стоит.

| | |
|---|---|
| `enter` | поставить: строка допишется в `settings.jsonc`, ownvim предложит перезапуститься |
| `ctrl-x` | убрать |
| `ctrl-o` | открыть страницу на GitHub |

### Вручную

```jsonc
"plugins": {
  "folke/zen-mode.nvim": { "cmd": "ZenMode", "opts": { "window": { "width": 100 } } },
  "folke/twilight.nvim": true,          // с настройками по умолчанию
  "folke/flash.nvim": false,            // убрать плагин встроенного модуля
},
```

Поля — как в [lazy.nvim](https://lazy.folke.io/spec): `opts`, `event`, `cmd`, `ft`, `keys`, `branch`, `version`…
Плагины ставятся и убираются после `:restart`. Управление установленными — `:Lazy` (`пробел l`).

## Свой модуль

Модуль — файл `lua/own/modules/<имя>.lua`, который возвращает таблицу:

```lua
-- Что делает модуль — одной-двумя строками (эта шапка попадает в справочник).
-- Настройки модуля: { "option": значение }
local M = {}

-- плагины для lazy.nvim (таблица или функция от настроек модуля)
function M.plugins(opts)
  return { { "автор/плагин", event = "VeryLazy", opts = {} } }
end

-- старт: opts — объект из modules.<имя> без поля enabled
function M.setup(opts) end

-- сохранили settings.jsonc — применить новые настройки на лету (необязательно)
function M.reload(opts) end

return M
```

И строка в `defaults.jsonc`, раздел `modules`: `"<имя>": true` (или объект с настройками и комментарием).

Правила, по которым написаны встроенные модули:

- **Настройки — только из JSON.** Всё, что пользователь может захотеть поменять, — в настройках модуля или в своём
  разделе `settings.jsonc` с пояснением в `defaults.jsonc`.
- **Применяться на лету**, если это возможно (`reload`); если нет — сказать, что нужен `:restart`.
- **Не замедлять старт.** Плагины — лениво (`event`, `cmd`, `ft`, `keys`), тяжёлое — после отрисовки (`vim.schedule`,
  `vim.defer_fn`), внешние программы — асинхронно (`vim.system`).
- **Ошибки — туда, где их видно.** Проблема настройки — `settings.warn(ключ, сообщение)`: подсветка на строке
  `settings.jsonc`.
- **Клавиши** — через действия в `lua/own/actions.lua` и строки в разделе `keys`, тогда они видны в `пробел sk`
  и в [справочнике](keys.ru.md).

После правки клавиш в `defaults.jsonc` обновите справочник:

```bash
NVIM_APPNAME=ownvim nvim --headless -l scripts/keys.lua > docs/keys.ru.md
```
