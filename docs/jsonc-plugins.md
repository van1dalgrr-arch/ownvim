# Плагины на JSONC — без кода

[← Документация](README.md) · 🇬🇧 [English](en/jsonc-plugins.md)

Набор — файл `extensions/<имя>.jsonc` с теми же разделами, что `settings.jsonc`: клавиши, задачи, проверки, команды,
блоки статусной строки, языковые серверы… Наборы ложатся слоями **между умолчаниями и вашим `settings.jsonc`** (он
всегда сильнее). Им удобно делиться: «всё для Go-бэкенда», «мои клавиши», «набор для Kubernetes» — один файл.

## Первый набор за минуту

1. `:PluginNew мой-набор` — появится `extensions/мой-набор.jsonc`, где каждый раздел расписан комментарием с примером.
2. Раскомментируйте нужное (`gcc` на строке), сохраните — **применилось сразу**, без перезапуска.
3. Выключить набор, не удаляя, — `"enabled": false`.

```jsonc
{
  "name": "мой-набор",
  "description": "что делает",
  "keys": { "n <leader>xg": ":Git status" },
  "checks": { "go vet": { "run": "go vet ./...", "pattern": "*.go" } },
}
```

## Что можно положить в набор

Любой раздел `settings.jsonc` ([справочник](configuration.md#справочник-разделов)). Чаще всего:

| раздел | что | пример |
|---|---|---|
| `keys` | клавиши | `"n <leader>xg": ":Git status"` |
| `tasks` | задачи (`пробел rr`) | `"list+": [{ "name": "сервер", "cmd": "go run ./cmd/api", "when": ["go.mod"] }]` |
| `checks` | свои проверки — ошибки на строках | ниже |
| `commands` | команды-скрипты на любом языке ([как](extensions.ru.md)) | `"UUID": { "run": "uuidgen", "input": "none", "output": "insert" }` |
| `statusline` | блок в статусной строке из вывода команды | `"custom": { "k8s": { "shell": "kubectl config current-context", "every_ms": 10000 } }`, `"right+": ["k8s"]` |
| `lsp` · `format` · `lint` | серверы, форматтеры, линтеры языка | `"lsp": { "servers": { "zls": true } }` |
| `modules` | включить и настроить модули | `"modules": { "minimap": true }` |
| `extensions` | настройки Go-расширений | `"extensions": { "examples": { "max_lines": 60 } }` |

Служебные поля набора: `name`, `description`, `enabled`. Ошибка в наборе (JSON, неизвестный раздел) подсвечивается на
его строке; сломанный набор пропускается, остальные работают.

## Списки: дописать, а не заменить

Списки при слиянии заменяются целиком: `"tasks": { "list": [ … ] }` уберёт все задачи по умолчанию. Чтобы
**дописать**, поставьте `+` после имени ключа:

```jsonc
"tasks": { "list+": [{ "name": "миграции", "cmd": "migrate up", "when": ["migrations"] }] },
"statusline": { "right+": ["k8s"] },
```

Это работает везде — и в наборах, и в `settings.jsonc`.

## Проверки: свой линтер в три строки

Раздел `checks`: команда запускается по событию (по умолчанию — сохранение), её вывод `файл:строка:столбец: текст`
становится замечаниями на строках — подчёркивание, Error Lens, «Проблемы» в нижней панели. Так подключается почти
любой инструмент, у которого есть такой формат вывода.

```jsonc
"checks": {
  "go vet": { "run": "go vet ./...", "pattern": "*.go" },
  "shellcheck": { "run": "shellcheck -f gcc ${file}", "pattern": "*.sh,*.bash" },
  "eslint": { "run": "npx eslint -f unix ${file}", "pattern": "*.ts,*.tsx" },
  "todo с автором": {
    "run": "rg -n --no-heading 'TODO\\(\\w+\\)' ${file}",
    "format": "^(?P<file>[^:]+):(?P<line>\\d+):(?P<message>.*)$",
    "severity": "info"
  },
}
```

| поле | что | по умолчанию |
|---|---|---|
| `run` | команда; подставляются `${file}`, `${root}`, `${file_dir}` | — |
| `pattern` | для каких файлов (через запятую) | `*` |
| `on` | события | `["BufWritePost"]` |
| `cwd` | где запускать: `root` — корень проекта, `file` — папка файла | `root` |
| `severity` | уровень находок: `error`, `warn`, `info`, `hint` | `warn` (или из вывода: `error:` / `warning:`) |
| `format` | регулярное выражение с группами `file`, `line`, `message` (и `col`, `severity`) | `файл:строка[:столбец]: [error:] текст` |
| `enabled` | `false` — выключить | — |

`:Checks` — прогнать проверки текущего файла сейчас. Каждая проверка ставит свои замечания и убирает свои прошлые, когда
их больше нет. Медленная проверка не мешает: всё идёт в фоне, новый прогон отменяет устаревший.

## Пример: набор для Go-бэкенда

```jsonc
// extensions/go-backend.jsonc
{
  "name": "go-backend",
  "description": "миграции, swag, vet при сохранении, контекст k8s в статусной строке",
  "checks": {
    "go vet": { "run": "go vet ./...", "pattern": "*.go" },
  },
  "tasks": {
    "list+": [
      { "name": "миграции вверх", "cmd": "migrate -path migrations -database $DATABASE_URL up", "when": ["migrations"] },
      { "name": "swag init", "cmd": "swag init -g cmd/api/main.go", "when": ["go.mod"] },
    ],
  },
  "keys": {
    "n <leader>xm": ":OverseerRun",
  },
  "statusline": {
    "custom": { "k8s": { "shell": "kubectl config current-context", "every_ms": 15000, "icon": "⎈", "color": "pink" } },
    "right+": ["k8s"],
  },
}
```

## Если не работает

| симптом | что делать |
|---|---|
| набор не применился | откройте его: ошибка подсвечена на строке; `"enabled": false`? |
| проверка молчит | `:Checks` — запустить сейчас; запустите `run` в терминале — вывод в формате `файл:строка: текст`? иначе — свой `format` |
| «нет программы» | поставьте инструмент (`brew install shellcheck`…) |
| набор перебил мою настройку | не может: `settings.jsonc` сильнее любого набора |

Нужно больше, чем умеет JSONC (своя логика, подсказки, панели)? — [Расширения на Go](go-extensions.md).
