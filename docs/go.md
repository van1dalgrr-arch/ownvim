## Запуск: ▶ у main и тестов

Слева от `func main`, `TestX`, `BenchmarkX`, `FuzzX`, `ExampleX` — значок ▶, как в GoLand.

| клавиша | что |
|---|---|
| `пробел rx` | запустить функцию под курсором: тест — через neotest (✓/✗ рядом), `main` — в терминале снизу |
| `пробел rX` | то же под отладчиком (delve) |
| `пробел rg` | Go-черновик: пустой `main.go` во временной папке |
| `пробел rr` / `alt-t` | задачи: `go run`, air, gotestsum, golangci-lint, govulncheck, pprof… ([Задачи](devops.md#задачи)) |

## Тесты

| клавиша | что |
|---|---|
| `пробел tr` | тест под курсором |
| `пробел tt` / `tT` | тесты файла / всего проекта |
| `пробел tl` | повторить последний |
| `пробел td` | тест под курсором в отладчике |
| `пробел to` / `tO` | вывод теста / панель вывода |
| `пробел ts` | дерево тестов |
| `пробел tw` | перезапускать при сохранении |

Результат — значками у теста. Упавшая проверка (`t.Errorf`) — ошибкой на её строке в `_test.go`.

```jsonc
"test": {
  "adapters": {
    "neotest-golang": { "go_test_args": ["-v", "-race", "-count=1", "-timeout=60s"] },
    "neotest-python": true,
  },
  "failed_as_error": true,   // сообщения упавшего Go-теста — ошибками, а не подсказками
},
```

### Тесты в фоне

Сохранили Go-файл — через секунду `go test` его пакета (из кэша — мгновенно). В статусной строке `✓ 42` / `✗ 1` /
`✗ сборка`, упавшая проверка подсвечена на своей строке — видно ещё до коммита. `пробел tA` — выключить/включить.

### Покрытие

`пробел Gv` — прогнать тесты и показать покрытие прямо в коде, `пробел GV` — спрятать/показать, `пробел Gs` —
проценты по файлам.

## Отладчик

nvim-dap + delve. Клавиши — как в GoLand (на маке F-клавиши через `fn`):

| клавиша | что |
|---|---|
| `F9` | запустить / дальше |
| `F8` / `F7` / `shift-F8` | шаг / внутрь / наружу |
| `ctrl-F8` | точка останова (`пробел dB` — с условием) |
| `пробел dC` | до курсора |
| `пробел de` | значение выражения |
| `пробел du` | панели отладчика |
| `пробел dt` | остановить |

Точки останова переживают перезапуск, панели переменных и стека открываются сами, значения переменных — серым
прямо в коде.

По умолчанию есть конфигурация **«Подключиться к dlv в Docker (:2345)»**: запустите в контейнере
`dlv debug ./cmd/api --headless --listen=:2345 --accept-multiclient --api-version=2` (порт 2345 наружу, код в `/app`),
и ownvim подключится, сопоставив пути. Свои конфигурации — как в nvim-dap-go:

```jsonc
"debug": {
  "go": {
    "configurations": [
      { "type": "go", "name": "API локально", "request": "launch", "program": "./cmd/api" }
    ]
  }
},
```

## Навигация и рефакторинг

| клавиша | что |
|---|---|
| `gd` / `gr` / `gI` / `gy` | определение / использования / реализации / тип |
| `gpd` / `gpr` / `gpi` / `gpt` | то же, но посмотреть в окне, не уходя с места |
| `пробел ch` / `cH` | кто вызывает / что вызывает |
| `пробел ca` | действия с превью |
| `пробел cx` | вынести функцию, переменную, константу |
| `пробел ci` | встроить вызов или переменную |
| `пробел cw` | переписать: заполнить struct, if ↔ else, параметры… |
| `пробел cr` / `shift-F6` | переименовать |

Рядом с типами — «реализует: io.Reader, fmt.Stringer».

## Генерация кода

Всё — под `пробел G`:

| клавиша | что |
|---|---|
| `пробел Gj` / `Gy` / `Gd` / `Gt` / `Gr` | теги `json` / `yaml` / `db` / свои / убрать |
| `пробел Gi` | реализовать интерфейс (курсор на типе) |
| `пробел Ge` | `if err != nil { return … }` с правильными нулевыми значениями |
| `пробел Gc` | doc-комментарий |
| `пробел Gf` / `GF` | тест для функции под курсором / для всех функций файла |
| `пробел Gp` | JSON → Go-структура |
| `пробел Gm` / `Gg` | `go mod tidy` / `go get` пакета |
| `пробел Go` | оптимизации компилятора: что ушло в кучу, что заинлайнилось |

Сниппеты: `ife`, `errw`, `tt` (табличный тест), `bench`, `gh` (Gin-хендлер) и другие.

## HTTP: эндпоинты и `.http`-запросы

- **`пробел re` / `alt-a`** (`:Endpoints`) — все маршруты Gin с полным путём, как окно Endpoints в GoLand: `enter` — к
  определению хендлера, `ctrl-r` — отправить запрос на запущенный API (токен из ответа логина запоминается), `ctrl-y` —
  скопировать curl. Код разбирается настоящим парсером (`go/ast`), без запуска: группы по цепочке
  (`api.Group("/v1").Group("/users")`) и группы, переданные в другие функции (`registerUsers(v1.Group("/users"))`).
- **`пробел rh` / `alt-p`** — `api.http` проекта, собранный из маршрутов.
- **`.http`-файлы** — Postman в файле, формат VS Code REST Client / JetBrains HTTP Client: `enter` на запросе
  отправляет его, ответ — в панели справа (`esc` — закрыть); `пробел Rc` — скопировать как curl. Переменные (`@host = …` → `{{host}}`) и ответы прошлых
  запросов (`{{login.response.body.$.access_token}}`).

```http
@host = http://localhost:8080

### Вход
# @name login
POST {{host}}/auth/login
Content-Type: application/json

{ "email": "a@b.c", "password": "secret" }

### Профиль
GET {{host}}/me
Authorization: Bearer {{login.response.body.$.access_token}}
```

```jsonc
"go": {

  "implements": true,                // «реализует: …» рядом с типом

},
"lsp": { "servers": { "gopls": { "settings": { "gopls": { "gofumpt": true, "staticcheck": true } } } } },
```
