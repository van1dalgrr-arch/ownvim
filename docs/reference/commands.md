# Команды

[← Документация](../README.md)

Команды ownvim (`:Имя`). Команды плагинов (`:Lazy`, `:Mason`, `:Glance`…) — в их документации; все сразу —
`cmd-shift-p` или `пробел sC`.

## Настройки и проверка

| команда | что | клавиша |
|---|---|---|
| `:Settings` | открыть свой `settings.jsonc` | `пробел fc` |
| `:Settings defaults` | открыть `defaults.jsonc` — все умолчания | `пробел fC` |
| `:OwnHealth` | проверка: настройки, программы, серверы, форматтеры, парсеры, шрифт, тема, скорость старта | `пробел uX` |
| `:restart` | перезапустить ownvim (нужно после включения модулей и плагинов) | |

## Внешний вид

| команда | что | клавиша |
|---|---|---|
| `:ThemeNew имя [основа]` | своя тема на основе другой; сохранили файл — перекрасилось | |
| `:ThemeEdit` | открыть файл текущей темы | |
| `:ThemeInstall издатель.имя` | тема из VS Code (Open VSX / Marketplace), `.vsix`, `.json` или путь | |
| `:IconTheme [имя]` | выбрать тему иконок | |
| `:IconThemeInstall ссылка` | поставить тему иконок из `.json` | |
| `:Font [имя]` | выбрать шрифт из установленных | |
| `:FontInstall имя` | поставить шрифт (brew: Google Fonts, Nerd Fonts) и включить | |

Выбор темы с предпросмотром — `alt-s` / `пробел uC`.

## Языки и инструменты

| команда | что |
|---|---|
| `:AutoTools` | какие языки ownvim настроил сам и что для них поставлено |
| `:AutoTools язык` | забыть язык — при следующем открытии файла решить заново |
| `:Mason` | серверы, форматтеры, линтеры: что поставлено (`пробел cm`) |
| `:DockerLayers` | выбрать образ, вес слоёв которого показывать в Dockerfile |
| `:TestsPanel` | панель «Тесты в фоне» (`пробел tv`) |
| `:AutoTests` | тесты в фоне: выключить / включить (`пробел tA`) |

## Расширение

| команда | что | клавиша |
|---|---|---|
| `:Plugins` | магазин плагинов: ~1400 плагинов awesome-neovim | `пробел L` |
| `:Lazy` | установленные плагины, обновление, ошибки установки | `пробел l` |
| `:Commands` | свои команды-скрипты | `пробел C` |
| `:ExtensionNew имя` | заготовка расширения `extensions/имя.py` и строка в `commands` | |
| `:GoExtensionNew имя` | заготовка расширения на Go: `core/extensions/имя/имя.go` ([руководство](../go-extensions.md)) | |
| `:GoExtensions` | что объявили Go-расширения: команды и события | |
| `:PluginNew имя` | JSONC-набор без кода: `extensions/имя.jsonc` с расписанными разделами ([руководство](../jsonc-plugins.md)) | |
| `:Checks` | прогнать свои проверки (раздел `checks`) для текущего файла | |
| `:View [имя]` | открыть или закрыть панель Go-расширения | |

## Удобство

| команда | что | клавиша |
|---|---|---|
| `:Quiet` | тихий режим: убрать всё, что отвлекает; ещё раз — вернуть | `пробел uq` |
| `:Rest` | начать перерыв (в статусной строке ☕ и отсчёт) | |
| `:RestLater` | напомнить о перерыве через 10 минут | |

## Заметки

| команда | что | клавиша |
|---|---|---|
| `:NoteAdd` | записать неудобство вместе с местом | `пробел ?` |
| `:Notes` | список заметок | `пробел N` |
