# Модули

[← Документация](../README.md)

Каждая возможность ownvim — модуль (`lua/own/modules/<имя>.lua`). Включить, выключить, настроить — раздел
`modules` в `settings.jsonc`:

```jsonc
"modules": { "minimap": true, "learn": false, "error_lens": { "preset": "classic" } },
```

Включение и выключение — после `:restart`; настройки модуля — обычно сразу.

## Интерфейс

| модуль | что делает | по умолчанию | настройки |
|---|---|---|---|
| `ui` | стартовый экран, уведомления, подсказка клавиш (which-key), линии отступов, колонка номеров | вкл | раздел `dashboard` |
| `themes` | темы и выбор с предпросмотром (`alt-s`) | вкл | раздел `theme`, `colors` |
| `icons` | темы иконок (material, default, backend…) | вкл | раздел `icons` |
| `font` | шрифт в Ghostty, `:Font`, `:FontInstall` | вкл | раздел `font` |
| `statusline` | своя статусная строка из блоков | вкл | раздел `statusline` |
| `tabline` | вкладки, как в VS Code | вкл | раздел `tabline` |
| `breadcrumbs` | папка › файл › тип › функция сверху | вкл | раздел `breadcrumbs` |
| `progress` | прогресс языковых серверов в углу (gopls индексирует — видно, а не «завис») | вкл | — |
| `workspace` | [рабочее место](../workspace.md): панели слева и снизу на своих местах, режимы `пробел 1…5`, конфигурации запуска, поиск везде; раскладка помнится для проекта | вкл | `restore`, `default`, `left_width`, `bottom_height` |
| `animations` | плавный курсор и прокрутка | вкл | раздел `animations` |
| `modes` | режим цветом курсора и строки; выход по `jk` / `ол`; выход из вставки после паузы (по умолчанию выключен) | вкл | `escape`, `escape_ms`, `auto_normal_ms` |
| `scrollbar` | полоса прокрутки с метками ошибок, git и найденного | вкл | — |
| `brackets` | цветные пары скобок | вкл | `colors` |
| `sticky_scroll` | шапка функции прилипает сверху | вкл | `max_lines` |
| `error_lens` | ошибки справа от строки, в том числе во время набора | вкл | `preset`, `break_after`, `insert`, `all_on_cursorline` |
| `quiet` | тихий режим (`пробел uq`): убрать подсказки типов, плашки ошибок, анимации, крошки… — ещё раз вернуть | вкл | `hide` |
| `rest` | напомнить о перерыве после 50 минут непрерывной работы; `:Rest` — перерыв с отсчётом | выкл | `work_min`, `break_min`, `show` |
| `dim` | неактивные окна тусклее (сплиты, дерево, терминал), плавно; `пробел uW` — выкл на время | вкл | `level`, `animate`, `style`, `by`, `except` |
| `minimap` | миникарта справа | **выкл** | `width` |
| `image_panel` | картинка сбоку, своя у каждой темы | **выкл** | `image`, `themes`, `side`, `width` |

## Код и языки

| модуль | что делает | по умолчанию | настройки |
|---|---|---|---|
| `lsp` | языковые серверы, ошибки, переходы, переименование, подсказки типов | вкл | разделы `lsp`, `diagnostics`, `tools`, `auto` |
| `treesitter` | подсветка, отступы, складки; парсеры ставятся сами | вкл | `languages`, `auto_install` |
| `completion` | автодополнение (blink.cmp), сниппеты | вкл | раздел `completion` |
| `format` | форматирование при сохранении (conform) | вкл | раздел `format` |
| `lint` | линтеры сверх сервера (nvim-lint) | вкл | раздел `lint` |
| `editing` | пары скобок, текстовые объекты, обрамление, прыжки flash, TODO | вкл | — |
| `multicursor` | мультикурсоры (`ctrl-n`, `пробел m`) | вкл | — |
| `dial` | `ctrl-a`/`ctrl-x` по своим циклам слов | вкл | циклы по языкам |
| `yanky` | история копирования (`пробел p`) | вкл | — |
| `commands` | свои команды-скрипты на любом языке | вкл | раздел `commands` |
| `checks` | свои проверки без кода: команда на событие, ошибки на строках | вкл | раздел `checks` |

## Go, тесты, отладка

| модуль | что делает | по умолчанию | настройки |
|---|---|---|---|
| `go` | ▶ у main и тестов, генерация, рефакторинги, «реализует», покрытие | вкл | раздел `go` |
| `test` | тесты (neotest): запуск, результаты, упавшие проверки на строках | вкл | раздел `test` |
| `autotest` | тесты Go в фоне после сохранения, `✓ 42` в статусной строке, панель «Тесты в фоне» (`пробел tv`); на Go | вкл | — |
| `debug` | отладчик (nvim-dap + delve / codelldb), F-клавиши как в GoLand | вкл | раздел `debug` |
| `http` | `.http`-запросы, эндпоинты Gin, `api.http` из маршрутов (на Go: `core/extensions/http`, `endpoints`) | вкл | — |
| `rust` | версии зависимостей в `Cargo.toml`, «Rust: собрать и отладить» (`F9`), задачи cargo | вкл | — |

## DevOps и данные

| модуль | что делает | по умолчанию | настройки |
|---|---|---|---|
| `docker` | живой compose.yaml, вес слоёв Dockerfile, `${VAR}` ↔ `.env` | вкл | `interval_ms`, `compose_status`, `layers`, `env_check` |
| `sql` | SQL (Postgres): сервер сам подключается к базе проекта; таблицы, колонки, типы и enum из миграций — и без базы; миграции: `пробел rm`, down пишется сам, ✓ / ○ в файле | вкл | `migrations`, `tool`, `auto_down`, `status`, `lsp_db` |
| `database` | базы данных (dadbod), подключение проекта из `.env` | вкл | раздел `database` |
| `tasks` | задачи (`пробел rr`) | вкл | раздел `tasks` |
| `system` | контейнеры (`alt-o`), GitHub (`alt-w`), скриншот кода | вкл | `containers`, `github` |
| `kubernetes` | kubectl.nvim (`пробел k`), если есть `kubectl` | вкл | — |
| `cloak` | секреты в `.env` под звёздочками | вкл | — |

## Работа

| модуль | что делает | по умолчанию | настройки |
|---|---|---|---|
| `basics` | подсветка скопированного, курсор на прошлом месте, `q` закрывает служебные окна | вкл | — |
| `picker` | поиск файлов, текста, команд (snacks) | вкл | — |
| `files` | yazi, найти-заменить по проекту, структурная замена | вкл | — |
| `git` | изменения на полях, blame, diffview, история, lazygit | вкл | раздел `git` |
| `ai` | Claude Code: панель, «почини ошибку», ревью ветки | вкл | раздел `ai` |
| `sessions` | сессии проектов | вкл | раздел `sessions` |
| `autosave` | автосохранение, подхват изменений снаружи | вкл | — |
| `comfort` | `enter` — прыжок на строку по меткам | вкл | — |
| `russian` | команды в русской раскладке | вкл | `langmap`, `alt_keys` |
| `learn` | подсказки движений, тренер привычек | выкл | `hints_visible`, `hardtime` |

Подробные настройки каждого модуля — комментарии в шапке его файла и в разделе `modules` файла `defaults.jsonc`.
