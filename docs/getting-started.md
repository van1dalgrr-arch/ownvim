## Что нужно

| | зачем |
|---|---|
| Neovim **0.12+** | сам редактор (`brew install neovim`) |
| git | установка плагинов |
| `tree-sitter` | сборка парсеров для подсветки (`brew install tree-sitter`) |
| `ripgrep` | поиск по проекту (`brew install ripgrep`) |
| Go | ядро ownvim (`core/`) собирается при первом запуске (`brew install go`); без Go работает запасной движок настроек |
| шрифт Nerd Font | значки; в Ghostty они встроены, подойдёт любой шрифт |

Рекомендуемый терминал — **Ghostty**: ownvim умеет менять в нём шрифт (`:Font`), показывать картинки
(протокол kitty) и прозрачный фон. В других терминалах всё остальное работает так же.

Необязательно, но используется, если стоит: `lazygit` (git), `yazi` (файлы), `docker` (модуль Docker),
`kubectl` (Kubernetes), `freeze` (скриншоты кода), ImageMagick (картинки jpg/webp), `trash` (удаление в корзину).

## Установка

```bash
brew install neovim tree-sitter ripgrep go
git clone https://github.com/van1dalgrr-arch/ownvim ~/dev/ownvim
ln -s ~/dev/ownvim ~/.config/ownvim
echo 'alias ownvim="NVIM_APPNAME=ownvim nvim"' >> ~/.zshrc && exec zsh
ownvim
```

`NVIM_APPNAME=ownvim` отделяет ownvim от обычного `nvim`: свои настройки (`~/.config/ownvim`), плагины и данные
(`~/.local/share/ownvim`). Ваш основной Neovim не затрагивается.

С [dotfiles](https://github.com/van1dalgrr-arch/dotfiles) всё это делает `install.sh`.

## Первый запуск

Первый запуск занимает около минуты: ownvim сам ставит плагины, парсеры языков, языковые серверы, форматтеры
и линтеры. Дальше код появляется на экране через ~70 мс после запуска.

Потом:

1. **`:OwnHealth`** — проверка, всё ли на месте: настройки, программы, серверы, шрифт. У каждой проблемы написано,
   как её исправить.
2. **`пробел fc`** — открыть свои настройки (`settings.jsonc`). Пока он почти пустой — всё берётся из умолчаний.
3. **`alt-s`** — выбрать тему: курсор по списку перекрашивает весь редактор сразу.

Открыли файл языка, для которого ничего не настроено, — сервер, форматтер и линтер для него поставятся сами
(подробнее — [Языки](languages.md#автоустановка)).

## 13 клавиш на первый день

`пробел` — главная клавиша (leader). Через секунду после неё снизу появляется подсказка: что можно нажать дальше.

| что | клавиша |
|---|---|
| начать печатать / закончить | `i` / `esc` или быстро `jk` (в русской раскладке — `ол`); после 5 с без набора — само |
| принять подсказку дополнения | `tab` или `enter` (серое продолжение в строке — тоже `tab`) |
| сохранить | `cmd-s` (файл и так сохраняется сам) |
| копировать / вставить / вырезать | `cmd-c` / `cmd-v` / `cmd-x` (без выделения — строка), `cmd-a` — всё, `cmd-z` — отмена |
| найти файл | `пробел пробел` или `cmd-p` |
| найти текст по проекту | `пробел /` |
| дерево файлов | `пробел e` |
| прыгнуть на строку | `enter` — у строк появятся буквы, нажмите нужную |
| к определению / где используется | `gd` / `gr` |
| описание под курсором | `K` |
| исправить ошибку, действия с кодом | `пробел ca` |
| все клавиши с поиском | `пробел sk` |
| выйти | `пробел qq` |

Команды работают и в русской раскладке (`о` = `j`, `Ж` = `:`) — переключать язык ради них не нужно.
Полный список — [Клавиши](keys.ru.md).

## Переход с VS Code

| VS Code | ownvim |
|---|---|
| `settings.json` | `settings.jsonc` (`пробел fc`) — тот же JSON с комментариями, с дополнением ключей и проверкой |
| Default Settings | `defaults.jsonc` (`пробел fC`) — все умолчания с пояснениями |
| Command Palette (`cmd-shift-p`) | `cmd-shift-p` — все команды; `пробел sk` — все клавиши и действия |
| Quick Open (`cmd-p`) | `cmd-p` или `пробел пробел` |
| поиск по проекту (`cmd-shift-f`) | `пробел /`; найти и заменить — `пробел sr` |
| Explorer | `пробел e` или значок слева |
| Extensions | `:Plugins` (`пробел L`) — каталог из ~1400 плагинов |
| Color Theme (`cmd-k cmd-t`) | `alt-s`; любая тема с Marketplace — `:ThemeInstall издатель.имя` |
| `workbench.colorCustomizations` | раздел `colors` |
| Terminal · Problems | нижняя панель: `пробел j`, вкладки — `пробел jt` / `jp` / `jo` |
| Go to Definition / References | `gd` / `gr` |
| Quick Fix (`cmd-.`) | `пробел ca` |
| Rename Symbol (`F2`) | `пробел cr` или `shift-F6` (`F2` — к следующей ошибке, как в GoLand) |
| Error Lens, Sticky Scroll, bracket colors, minimap | модули `error_lens`, `sticky_scroll`, `brackets`, `minimap` |
| Source Control | `alt-g` (lazygit), изменения на полях, `пробел gm` — ветка против main |
| Run and Debug | `F9` — запуск, `F8` — шаг, `ctrl-F8` — точка останова (как в GoLand) |
| Tasks (`tasks.json`) | раздел `tasks`, запуск — `пробел rr` |
