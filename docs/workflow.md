## Поиск

| клавиша | что |
|---|---|
| `пробел пробел` | везде: файлы, действия, запуск, режимы, темы ([рабочее место](workspace.md#поиск-везде)) |
| `cmd-p` / `пробел ff` | найти файл в проекте |
| `пробел /` | текст по проекту (`пробел sw` — слово под курсором) |
| `пробел ,` | открытые буферы |
| `пробел fr` / `fR` | недавние файлы / недавние в этой папке |
| `пробел fp` | проекты |
| `пробел ss` / `sS` | символы файла / проекта |
| `пробел sd` / `sD` | ошибки проекта / файла |
| `пробел sr` | найти и заменить по проекту (grug-far) |
| `пробел sA` | структурная замена по коду (ast-grep) |
| `пробел sR` | вернуть прошлый поиск |

В окне поиска `alt-c` переключает область: проект ↔ папка, где запущен ownvim.

## Дерево файлов

`пробел e` (или значок слева). Своё дерево ownvim: git — цветом и буквой (`M`, `U`, `A`, `D`), `●` у файлов и
папок с ошибками, открытый файл подсвечен, папка с одной папкой — одной строкой (`internal/user/repo`), значки папок —
из [темы иконок](appearance.md#иконки).

| в дереве | |
|---|---|
| `enter` / `l` · `h` | открыть · свернуть |
| `a` | создать (`/` в конце — папка) |
| `r` · `d` | переименовать · удалить (в корзину, если стоит `trash`) |
| `c` / `x` / `p` | копировать / вырезать / вставить |
| `y` · `s` | скопировать путь · открыть справа |
| `H` · `-` · `.` | скрытые файлы · папка выше · сделать корнем |
| `?` · `q` | помощь · закрыть |

```jsonc
"explorer": { "side": "left", "width": 32, "hidden": false, "compact": true, "indent": "│ ", "git": true },
```

`"engine": "snacks"` — вернуть дерево snacks. Файловый менеджер yazi — `пробел fy` (у файла) / `пробел fY` (в корне).

## Правка

- Парные скобки и кавычки, комментарии `gcc` / `gc`.
- Текстовые объекты: `af`/`if` — функция, `ac`/`ic` — тип, `ao`/`io` — блок.
- Обрамление: `gsa` — добавить, `gsd` — убрать, `gsr` — заменить.
- Выделенные строки: `J` / `K` — сдвинуть, `<` / `>` — отступ (выделение остаётся).
- Мультикурсоры: `ctrl-n` — курсор на следующем таком же слове, `пробел m` — меню, `alt`+клик — поставить.
- История копирования: `пробел p` — вставить любое из скопированного.
- `ctrl-a` / `ctrl-x` — не только числа: `true` ↔ `false`, даты, а для Go — `:=` ↔ `=`, `Error` ↔ `Fatal`,
  HTTP-методы и статусы (свои циклы — в настройках модуля `dial`).
- TODO / FIXME подсвечены и ищутся (`пробел st`).
- История правок файла без git — `пробел U`.

## Движение без мыши

- **`enter`** — у всех строк экрана появляются буквы, нажали букву — вы там.
- **`s`** — прыжок по буквам, **`S`** — по узлам кода (flash).
- **Подсказки движений** в строке — `пробел uP`. **Тренер привычек** (hardtime) подсказывает, как короче, и ничего
  не запрещает; `пробел uH` — вкл/выкл, `пробел uR` — какие привычки встречаются чаще.

### Выход из вставки

Быстро `jk` (или `ол` в русской раскладке) — выход из вставки: если за 200 мс после `j` пришла `k`, ownvim стирает
`j` и выходит. В отличие от обычной привязки `"i jk"`, `j` не висит «в ожидании» — она сразу становится текстом, и
дополнение не ждёт; а `ол` обычной привязкой не сделать вовсе. Если не печатать 5 секунд, вставка закончится сама.

```jsonc
"modules": { "modes": { "escape": ["jk", "ол"], "escape_ms": 200, "auto_normal_ms": 5000 } },  // [] / 0 — выключить
```

## Русская раскладка

Команды работают без переключения языка: `о` = `j`, `л` = `k`, `вв` = `dd`, `Ж` = `:`. В режиме вставки буквы
печатаются как есть. alt-сочетания дублируются сами (`alt-щ` = `alt-o`).

```jsonc
"modules": { "russian": { "langmap": true, "alt_keys": true } },
```

## Git

| клавиша | что |
|---|---|
| `alt-g` / `пробел gg` | lazygit |
| `]h` / `[h` | к следующему / предыдущему изменению |
| `пробел ghs` / `ghr` / `ghp` | кусок — в коммит / вернуть / показать, что было |
| `пробел uB` | blame строки серым справа (`пробел ghb` — коммит целиком) |
| `пробел gv` | все изменения и конфликты (diffview, merge в три панели) |
| `пробел gm` | ветка против main — как PR |
| `пробел gH` | история файла |
| `пробел gs` / `gl` / `gc` | изменённые файлы / коммиты / ветки |
| `пробел gB` | открыть строку на GitHub |

```jsonc
"git": {
  "blame": false,
  "blame_format": "<author>, <author_time:%d.%m.%Y> · <summary>",
  "base_branch": "auto",   // с чем сравнивать ветку: origin/HEAD, или "main", "develop"
},
```

## Claude

Claude Code внутри ownvim (модуль `ai`):

| клавиша | что |
|---|---|
| `alt-c` | показать / спрятать панель Claude (из любого места, и из терминала) |
| `пробел ax` | «почини ошибку под курсором» |
| `пробел as` | отправить выделенное |
| `пробел ab` | добавить файл в контекст |
| `пробел ay` / `an` | принять / отклонить правку |
| `пробел aR` | ревью ветки: Claude читает diff против main, замечания — на строках, как ошибки; списком — в «Проблемах» |
| `пробел aX` | убрать замечания ревью |

```jsonc
"ai": { "side": "right", "width": 0.4 },
```

Файлы, которые Claude поменял, подхватываются в открытых буферах сами.

## Сессии

Закрыли ownvim в проекте — открыли там же без файлов — вернулись вкладки, разбиения и места курсора.

| клавиша | что |
|---|---|
| `пробел qs` | вернуть сессию этой папки |
| `пробел qS` | выбрать из всех |
| `пробел qd` | не сохранять эту сессию |

```jsonc
"sessions": { "auto_save": true, "auto_restore": true, "ignore": ["~", "/tmp", "/"] },
```

## Автосохранение

Файл записывается сам: вышли из вставки, поправили в обычном режиме, ушли в другое окно. Запись запускает
форматирование. Файлы, изменённые снаружи (git, Claude, `go generate`), подхватываются сами.
Выключить на время — `:let g:autosave = v:false`.

## Тихий режим и отдых

**Тихий режим — `пробел uq`** (`:Quiet`): когда нужно просто подумать и писать, убирает всё, что отвлекает, — подсказки
типов, плашки ошибок, надписи над кодом, blame, «реализует», анимации, линии отступов, липкую шапку, хлебные крошки,
полосу прокрутки. Ошибки не пропадают: значки слева и подчёркивания остаются. В статусной строке — «тихо», чтобы не
забыть. Ещё раз `пробел uq` — всё как было (ровно то, что было включено).

```jsonc
"modules": { "quiet": { "hide": ["inlay_hints", "error_lens", "animations", "breadcrumbs"] } },  // прятать только это
```

**Отдых.** ownvim считает время непрерывной работы: через 50 минут — одно мягкое уведомление и «⏱ пора отдохнуть»
в статусной строке (никаких часов, которые подгоняют). Пауза дольше 5 минут — уже перерыв, счёт заново.
`:Rest` — начать перерыв (в строке ☕ и обратный отсчёт), `:RestLater` — напомнить через 10 минут.

```jsonc
"modules": { "rest": { "work_min": 50, "break_min": 5, "show": "always" } },  // always — показывать время работы всегда
"modules": { "rest": false },                                                // без напоминаний
```

## Заметки о неудобствах

Чтобы ownvim развивался от реальной работы, а не от «было бы круто»:

- **`пробел ?`** — «что неудобно?»: пара слов, а место ownvim запишет сам — проект, файл, строку, режим, тип файла,
  последнюю команду и выделенный текст (если нажать в выделении).
- **`пробел N`** (`:Notes`) — список, новые сверху, справа — файл на нужной строке. `enter` — к месту,
  `ctrl-x` — решено (убрать), `ctrl-y` — все заметки в буфер обмена в markdown.

Заметки хранятся в данных редактора (`~/.local/share/ownvim/own-notes.json`), не в проекте.
