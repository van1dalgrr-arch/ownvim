## Два файла

| файл | что в нём | открыть |
|---|---|---|
| `defaults.jsonc` | все умолчания, у каждой строки — пояснение. Это справочник, его не правят | `пробел fC`, `:Settings defaults` |
| `settings.jsonc` | **только то, что меняете вы**. Удалили строку — вернулось умолчание | `пробел fc`, `:Settings` |

Оба файла — JSONC, как `settings.json` в VS Code и Zed: комментарии `//` и `/* */`, запятые в конце разрешены.

```jsonc
{
  "theme": "sunset",
  "options": { "relativenumber": true },
  "statusline": { "style": "arrows" },
}
```

## Как сливаются настройки

Слои накладываются друг на друга, каждый следующий сильнее:

```
defaults.jsonc  →  JSONC-наборы  →  языки, включённые автоматически  →  settings.jsonc
(умолчания)        (extensions/*.jsonc)  (own-auto.json, см. «Языки»)    (ваше — главнее всего)
```

- **Объекты сливаются по ключам.** Достаточно написать одну строку раздела — остальное возьмётся из умолчаний:
  `"statusline": { "style": "arrows" }` меняет только стиль.
- **Списки и значения заменяются целиком.** `"tasks": { "list": [ … ] }` заменяет весь список задач.
- **`true` поверх объекта** оставляет объект: `"modes": true` значит «включён, с настройками по умолчанию».
- **`{}` — пустой объект, а не «стереть всё»:** `"keys": {}` не убирает клавиши по умолчанию.
- **`"ключ+"` — дописать к списку:** `"tasks": { "list+": [ своя задача ] }` добавляет к задачам по умолчанию, а не
  заменяет их.
- **JSONC-наборы** (`extensions/*.jsonc`) — слои между умолчаниями и `settings.jsonc`: [Плагины на JSONC](jsonc-plugins.md).

## Когда применяется

**Сохранили `settings.jsonc` — применилось сразу:** тема, цвета, опции, клавиши, статусная строка, вкладки,
иконки, шрифт, языковые серверы (новые `settings` уходят в работающий сервер без перезапуска), форматтеры,
линтеры, настройки большинства модулей.

**После `:restart`** (ownvim скажет об этом сам): включить или выключить модуль, добавить или убрать плагин,
стартовый экран, адаптеры тестов, конфигурации отладчика. Что именно — в колонке «сразу?» [справочника](#справочник-разделов).

## Подсказки и проверка

- **Дополнение, как в VS Code.** В `settings.jsonc` дополняются ключи и значения: темы, стили, модули, действия
  для клавиш, 400+ языковых серверов. `K` на ключе — его описание из `defaults.jsonc`. Схема собирается сама
  из умолчаний, тем и модулей.
- **Ошибка видна сразу.** Сломанный JSON, неизвестный раздел, опечатка в имени модуля, опции или действия —
  подсветка на строке с объяснением. Редактор при этом продолжает работать на прошлых настройках.
- **Совсем сломалось** — переименуйте `settings.jsonc`: ownvim запустится на умолчаниях.

## Модули

Возможности разложены по модулям (`lua/own/modules/<имя>.lua`). Включить, выключить или настроить — раздел `modules`:

```jsonc
"modules": {
  "minimap": true,                                   // включить
  "learn": false,                                    // выключить
  "modes": { "auto_normal_ms": 0, "escape": ["jk"] }, // настроить (и включить)
}
```

Список всех модулей с настройками — [Модули](reference/modules.md).

## Клавиши

```jsonc
"keys": {
  "n <leader>z": ":Lazy",                              // команда
  "n <leader>ff": "files.git",                         // действие ownvim (список — пробел sk)
  "n <D-b>": "explorer",                               // cmd-b — дерево, как в VS Code
  "n <leader>uH": false,                               // убрать клавишу
  "n <leader>y": { "do": "\"+y", "desc": "В системный буфер", "remap": false },
}
```

Перед клавишей — режимы, буквами подряд: `n` обычный, `i` вставка, `x` выделение, `s` выбор, `o` после оператора,
`t` терминал, `c` командная строка (`nx` — в обычном и выделении). Значение — имя действия, клавиши как есть
(`"<C-w>h"`), команда (`":Lazy"`), объект `{ "do", "desc", "remap" }` или `false`. alt-сочетания сами дублируются
для русской раскладки. Все клавиши — [Клавиши](keys.ru.md).

## Опции Neovim

```jsonc
"options": { "relativenumber": true, "wrap": true, "scrolloff": 8 },  // любые :help options
"globals": { "autoformat": false },                                    // vim.g.*
```

Неизвестная опция подсвечивается в `settings.jsonc`.
