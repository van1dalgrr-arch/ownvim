# Рабочее место

[← Документация](README.md)

ownvim раскладывает экран, как IDE: у каждого окна своё место, и раскладка не разваливается, сколько панелей ни
открывай. Открыл проект — всё стоит, как ты оставил.

## Как устроен экран

```
┌─ 󰉋 󰙅 󰙨  ──────┬─ main.go  user.go ──────────────────────── 󰙨 Тесты │  api ▾  ▶  󰃤 ─┐
│ ПРОЕКТ          │ cmd › api › main.go                                                    │
│ ▾ cmd           │   1  package main                                                      │
│   ▾ api         │   …                                                                    │
│      main.go    ├────────────────────────────────────────────────────────────────────────┤
│ ▸ internal      │  Терминал   api   Проблемы 2   Задачи   Вывод тестов                   │
│                 │ listening on :9090                                                     │
└─────────────────┴────────────────────────────────────────────────────────────────────────┘
```

- **Слева** — один вид за раз: **Проект** (дерево файлов), **Структура** (символы файла), **Тесты**, **База**.
  Переключатель — значки над панелью, в строке вкладок: клик — открыть, клик по открытому — спрятать.
- **Снизу** — тоже один вид за раз: **Терминал**, **Запуск** (вывод запущенной конфигурации), **Проблемы** (ошибки
  всего проекта, `enter` — к строке), **Задачи**, **Вывод тестов**. Вкладки — в шапке панели, по ним можно кликать.
- **Справа вверху** — что сейчас запускается и режим, если он не «Код».

Боковые панели — на тон темнее кода, чтобы взгляд не цеплялся за них. Размеры фиксированы: открытая справка, список
или терминал не сдвигают дерево и не лезут в середину. Закрыл последний файл — ownvim закрылся, а не остался с одним
деревом.

| клавиша | что |
|---|---|
| `пробел e` | дерево проекта (ещё раз — спрятать) |
| `пробел co` | структура файла |
| `пробел ts` | дерево тестов |
| `пробел D` | база данных |
| `пробел 0` | спрятать / вернуть левую панель целиком |
| `пробел j` | спрятать / вернуть нижнюю панель целиком |
| `пробел jt` · `jr` · `jp` · `jo` · `jT` | терминал · запуск · проблемы · задачи · вывод тестов |
| `пробел cu` / `alt-F7` | **использования** символа под курсором — списком по файлам внизу, как Find Usages в GoLand |
| `пробел cU` · `пробел cM` | кто вызывает функцию · реализации интерфейса (там же) |
| `ctrl-/` | терминал снизу (ещё раз — спрятать; процесс живёт) |
| `q` | в любой панели — закрыть её |

**Раскладка помнится для каждого проекта:** какой вид был слева, какой снизу, в каком режиме ты был. Новый проект
открывается с деревом слева (это меняется в настройках).

## Режимы

Одна клавиша — экран под дело:

| клавиша | режим | что на экране |
|---|---|---|
| `пробел 1` | **Код** | то, что было открыто до другого режима |
| `пробел 2` | **Тесты** | дерево тестов слева (`пробел tr` — тест под курсором, `пробел tt` — файл) |
| `пробел 3` | **Отладка** | переменные, стек, точки останова, консоль; остальные панели убраны |
| `пробел 4` | **Git** | все изменения ветки: список файлов и diff (diffview) |
| `пробел 5` | **База** | подключения и таблицы слева |

Та же клавиша ещё раз — обратно в «Код», всё возвращается как было. `:Mode test` — то же командой.

## Запуск и отладка

Справа в строке вкладок — **конфигурация запуска**, как в GoLand: `  api ▾  ▶  󰃤`. ownvim находит их сам:

- **Go** — каждый `package main` (`./cmd/api`, `./cmd/worker`, корень); `.env` проекта подхватывается сам;
- **Rust** — `cargo run`; **compose** — `docker compose up`; **package.json** — `npm run dev` / `start`;
- **задачи** из раздела `tasks`, которым не нужно ничего спрашивать при запуске;
- **свои** — раздел `run` (ниже).

| клавиша | что |
|---|---|
| `пробел rr` | ▶ запустить (уже идёт — перезапустить) |
| `пробел rd` | запустить под отладчиком (Go — delve, Rust — codelldb); экран переходит в режим «Отладка» |
| `пробел rs` | ■ остановить |
| `пробел rc` | выбрать конфигурацию (или клик по имени справа вверху) |
| `пробел rx` / `rX` | запустить / отладить **функцию под курсором** (`main`, `TestX`) — как ▶ на полях |
| `пробел rt` | задачи (весь список, с вопросами) |

Вывод — во вкладке «Запуск» нижней панели, курсор остаётся в коде. Выбранная конфигурация помнится для проекта.

Свои конфигурации — в `settings.jsonc`:

```jsonc
"run": {
  "configs": [
    { "name": "api :8080", "cmd": "go run ./cmd/api -port 8080", "env": ".env" },
    { "name": "web", "cmd": "npm run dev", "cwd": "web" },
    { "name": "api (отладка с флагами)", "cmd": "go run ./cmd/api",
      "debug": { "type": "go", "request": "launch", "program": "${workspaceFolder}/cmd/api", "args": ["-port", "8080"] } },
  ],
},
```

> **macOS: отладка висит на «Building…»?** delve запускает программу через системный `debugserver`, а тот без
> режима разработчика каждый раз ждёт пароль в отдельном окне. Включить один раз: `sudo DevToolsSecurity -enable`.
> `:OwnHealth` покажет, включён ли он.

## Поиск везде

**`пробел пробел`** — одно окно на всё, как Search Everywhere (двойной shift) в GoLand: печатаешь, что нужно, а не
вспоминаешь, какой клавишей это ищется.

- файлы проекта;
- **действия** ownvim — с клавишей справа, чтобы она запоминалась сама (`форматировать`, `blame`, `покрытие`…);
- конфигурации запуска (`запустить worker`), режимы, темы.

`#` первым символом — символы проекта (типы, функции) через языковой сервер. Только файлы — `cmd-p` или
`пробел ff`.

## Настройки

```jsonc
"modules": {
  "workspace": {
    "restore": true,                                // открыть проект, как оставил
    "default": { "left": "tree", "bottom": false }, // новый проект: слева дерево, снизу ничего
    "left_width": 32,
    "bottom_height": 12,
  },
},
```

`left` — `tree`, `outline`, `tests`, `db` или `false`; `bottom` — `terminal`, `problems`, `tasks`, `test_output` или
`false`. Модуль выключается как любой другой: `"workspace": false` — панели открываются где придётся, как в обычном
Neovim.
